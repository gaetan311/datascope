# datascope
DataScope Studio : workspace d'analyse de données en Python (Streamlit). Importez CSV, Excel, JSON, Parquet, PDF ou HTML, puis explorez vos données, testez vos hypothèses, préparez et joignez vos jeux de données, créez des tableaux de bord interactifs et anticipez les tendances grâce à la prédiction. Studio code intégré ! Données de démo fournies.
